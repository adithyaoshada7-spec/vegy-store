# Ranketha Organics Foods - Website Demo

Demo duplicate of the organic foods & traditional rice website, customized for **Ranketha Organics Foods**.

---

## 🚀 How to Run the Demo

### Option 1: Direct Browser Open (Offline / Instant)
Simply double-click **`index.html`** to open the site directly in any web browser (Chrome, Edge, Firefox).

### Option 2: Local Web Server (Recommended)
Double-click **`start_demo.bat`** to start a local web server at:
👉 **`http://localhost:3000/index.html`**

---

## 📄 Pages Included

1. **Home (`index.html`)** - Full homepage with hero banners, category carousel, featured products, promotional sections, customer testimonials, and footer.
2. **Shop (`shop.html`)** - Product catalog with live search filter and category browsing.
3. **About Us (`about.html`)** - Brand story, mission, and organic commitment.
4. **Contact (`contact.html`)** - Contact details, store information, FAQ, and interactive contact form.

---

## 🎨 Customizations & Highlights

- **Brand Replacement**: All occurrences of "Nature's Corner" replaced with **Ranketha Organics Foods**.
- **Custom Logo**: Vector SVG logo featuring organic paddy stalks & fresh leaves with Sri Lankan organic styling.
- **Local Assets**: All images, banners, product thumbnails, payment icons, and styles are stored locally in the folder.
- **Interactivity (`interactive.js`)**:
  - Auto-cycling hero banner carousel and reviews slider
  - Interactive "Add to Cart" with quantity badge counter and popup notification
  - Real-time live product search
  - Mobile responsive drawer menu
  - Category dropdown menu
- **Privacy & Cleanliness**: All external tracking scripts (Facebook Pixel, Google Tag Manager, 3CX live chat) have been removed.
